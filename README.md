# Refleksi AI Mahasiswa PPG

Aplikasi berbasis Flask yang membantu mahasiswa PPG melakukan analisis refleksi pembelajaran menggunakan Google Gemini AI.

## Fitur

- Dashboard
- Manajemen Mata Kuliah
- Upload Modul
- Upload Artefak
- Analisis AI
- Export Word
- Preview PDF
- Multi Upload
- Dark Mode

## Teknologi

- Python
- Flask
- Bootstrap 5
- Google Gemini AI

## Cara Menjalankan

```bash
pip install -r requirements.txt
python app.py
```
