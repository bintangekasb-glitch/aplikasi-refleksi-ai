Aplikasi Refleksi AI Mahasiswa PPG

Versi 1.0.0

Deskripsi

Aplikasi ini membantu mahasiswa Pendidikan Profesi Guru (PPG) menyusun refleksi pembelajaran secara otomatis menggunakan teknologi Artificial Intelligence (AI).

Fitur

  • Membaca dokumen PDF
  • Membaca DOCX
  • Membaca PPTX
  • Membaca XLSX
  • Analisis menggunakan Google Gemini AI
  • Menyimpan hasil analisis
  • Ekspor ke Microsoft Word
  • Dashboard statistik
  • Logging proses aplikasi

Teknologi

  • Python
  • Flask
  • Bootstrap 5
  • Google Gemini API
  • python-docx
  • PyPDF2
  • openpyxl

Tujuan

Aplikasi ini dikembangkan sebagai media pendukung penyusunan refleksi pembelajaran mahasiswa PPG agar proses analisis dokumen menjadi lebih efektif, efisien, dan terdokumentasi dengan baik.
